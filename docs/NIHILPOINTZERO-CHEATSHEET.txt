RUN IT ............ EITHER double-click NIHILPOINTZERO-OS-portable.exe (portable; unpacks ~40-60s)
                    OR run NIHILPOINTZERO-OS-setup.exe ONCE to install -> opens in ~2s from then on,
                    taskbar pins are SAFE, and it uses the SAME data folder (same videos/settings).
MOVE IT ........... copy the WHOLE "NihilPointZeroStudio" folder -> paste on any PC -> run the portable exe
GOLDEN RULE ....... keep the .exe and "nihilpointzero-data" folder together, always
BUILD BADGE ....... the sidebar (under "OS") shows e.g. "v0.1.1 · 2026-07-19 15:59 · 4e5e704"
                    (version · exact build date+time · code id). Written AUTOMATICALLY at build time —
                    THAT is proof of which build is running. Don't see the expected badge? See below.
DON'T PIN THE RUNNING PORTABLE EXE ... a taskbar/Start pin made while the PORTABLE app is open freezes
                    to a temporary copy and keeps launching OLD code forever. (The INSTALLED version
                    has no such trap — pin it freely.) This was the #1 cause of "my updates didn't show".
MAKE SHORTS ....... Video Studio -> any video -> "📱 Cut into vertical shorts" -> it finds the best
                    moments itself and makes 9:16 captioned clips for Shorts/TikTok (free, offline)
STUCK? ASK IT .... click 🎬 Producer (bottom-right of EVERY tab) and ask "how do I ...?" — it knows every
                    tab and button of this studio and gives you the exact steps. 📖 Detailed / ⚡ Brief
                    buttons set how long the answer is.
JUMP ANYWHERE ..... press Ctrl-K, type a tab (e.g. "scene"), Enter
AUTOSAVE .......... work saves itself ("Saved ✓" near the title) and survives restart
BACKUPS ........... automatic weekly copy to C:\Users\<you>\NihilPointZero-Backups. Lost something?
                    Settings -> Backups -> "Restore missing files" (never overwrites current work).
                    Optional second home (USB) + delete-sync (delete in app = gone from backup too).
ONLY YOU DELETE ... every delete asks you to confirm; the AI can create/edit but NEVER deletes.
                    Deleting a video also removes its backup copy (delete-sync, off-switch in Settings).
RED DOT on Settings = the weekly self-check found a real problem -> open Settings -> Run full check
IF A CHANGE DOESN'T SHOW ... check the BUILD BADGE. If it's old: you launched a stale taskbar/Start
                    pin — use the Desktop shortcut or the .exe directly, then fully close + reopen.
